# Blog App

A full-stack blog application that allows users to create, share, and interact with blog posts.

## Features

- User Registration and Login
- JWT-based Authentication
- Create Blog Posts
- Upload Images and Videos
- Add Captions to Posts
- Like Posts
- Comment on Posts
- Delete Posts
- User Logout

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- JWT

### Database
- MySQL
